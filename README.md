# 📱 iPhone Sales Analysis & Visualization

## Project Overview
An interactive Streamlit dashboard that analyzes iPhone sales data and presents sales, revenue, model, regional, and monthly trends through interactive visualizations.

## Objectives
- Analyze iPhone sales data.
- Compare models and regions.
- Analyze revenue.
- Visualize monthly sales trends.
- Provide an interactive dashboard.

## Features
- Model and region filters
- KPI cards
- Units-sold comparison
- Regional sales chart
- Revenue chart
- Monthly sales trend
- Filtered data table
- CSV download

## Technologies
Python, Pandas, NumPy, Plotly, Streamlit, GitHub.

## Installation
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Usage
Open the Streamlit URL, select filters in the sidebar, explore the charts, and download filtered data if needed.

## System Workflow
```text
Dataset → Data Loading → Filtering/Processing → Analysis → Visualizations → Streamlit Dashboard → User Insights
```

## Testing / Results
Dataset loading, filtering, KPI calculations, charts, dashboard rendering, data table, and CSV download were tested in the project workflow.

## Challenges
Data preparation, choosing useful visualizations, interactive filtering, dashboard design, and deployment.

## Future Improvements
Sales forecasting, date-range filtering, geographic maps, profit analysis, machine-learning predictions, and live database integration.

## Conclusion
The project demonstrates how Python data-analysis and visualization tools can transform sales records into an interactive dashboard for exploring iPhone sales performance.
