# Deployment Guide

## GitHub
Create a repository and upload:
- app.py
- requirements.txt
- README.md
- FINAL_SUBMISSION.md
- data/iphone_sales.csv

Keep the `data` folder and CSV path unchanged.

## Streamlit
1. Open Streamlit Community Cloud.
2. Sign in with GitHub.
3. Choose Create app.
4. Select your repository and branch.
5. Set Main file path to `app.py`.
6. Click Deploy.
7. Copy the generated live URL.

Then replace the two URL placeholders in README.md.

## Screenshots
Run the deployed application and take screenshots of:
- dashboard
- sales chart
- revenue chart
- monthly trend

Place them in `screenshots/`.
